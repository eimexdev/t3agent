# Reuse Hermes voice transcription

T3 Agent sends voice notes through Hermes's existing gateway voice pipeline rather than owning speech-to-text behavior. Hermes remains responsible for transcription, configured media limits, and agent-run preparation; T3 Agent owns recording, durable audio presentation, and projecting the returned transcript into the originating voice-note message instead of showing a separate transcript echo. Hermes can accept combined voice-and-text input, but the initial T3 Agent composer intentionally keeps voice notes separate from typed content. Voice support is an additive, capability-gated extension to bridge protocol v1: the controlled T3 Hermes adapter uses a narrow Hermes voice-preparation lifecycle, reports transcription state by stable message and voice-attachment identity, and releases the normal agent run only after transcription succeeds.
